# Tech Verse QR

যেকোনো তথ্যকে এক ক্লিকে **QR কোডে** রূপান্তর করার জন্য একটি সম্পূর্ণ ব্রাউজার-ভিত্তিক টুল — কোনো ব্যাকএন্ড ছাড়াই, কোনো ডেটা সার্ভারে সংরক্ষণ ছাড়াই। Vanilla JavaScript দিয়ে তৈরি, সম্পূর্ণ ফ্রি এবং হালকা।

## ✨ বৈশিষ্ট্য

- **৮ ধরনের QR কোড** — এক টুলেই সব:
  - URL / লিংক
  - টেক্সট
  - WiFi (SSID + পাসওয়ার্ড)
  - কন্টাক্ট কার্ড (vCard) — সরাসরি `.vcf` ডাউনলোড
  - প্রি-ফিল্ড ইমেইল
  - ফোন কল শর্টকাট
  - প্রি-ফিল্ড SMS
  - ক্যালেন্ডার ইভেন্ট — সরাসরি `.ics` ডাউনলোড
- **স্মার্ট / ব্র্যান্ডেড QR** — QR স্ক্যান করলে সরাসরি র-ডেটা না দেখিয়ে প্রথমে সাইটের নিজস্ব ল্যান্ডিং পেজ (`?view=scan`) খোলে, তারপর ব্র্যান্ডিং সহ অ্যাকশন বাটনে ক্লিক করলে আসল কাজ (ভিজিট / সেভ / কল) সম্পন্ন হয়।
- **কাস্টমাইজেশন** — QR রং (foreground/background), সাইজ (200–600px), এরর কারেকশন লেভেল (L/M/Q/H)।
- **PNG ডাউনলোড** — তৈরি করা QR সরাসরি ইমেজ হিসেবে ডাউনলোড করা যায়।
- **প্রাইভেসি-ফার্স্ট** — কোনো তথ্য সার্ভারে যায় না; সব ডেটা QR-এর লিংকের ভেতরেই এনকোড থাকে এবং পুরো প্রসেস ব্রাউজারে ঘটে।
- **সম্পূর্ণ Responsive** — মোবাইল ও ডেস্কটপ উভয়ের জন্য উপযুক্ত।

## 🗂️ প্রজেক্ট স্ট্রাকচার

```
genaret-easily-qrcode-main/
├── index.html            # সিঙ্গেল-পেজ অ্যাপ (হোম, জেনারেটর, সম্পর্কে, স্ক্যান ভিউ)
├── 404.html               # কাস্টম ৪০৪ পেজ
├── css/
│   ├── base.css           # ডিজাইন টোকেন, রিসেট, টাইপোগ্রাফি, বাটন
│   ├── layout.css         # হেডার, নেভ, ফুটার
│   ├── home.css            # হিরো, ফিচার গ্রিড, CTA, About সেকশন
│   ├── generator.css      # QR জেনারেটর UI
│   └── scan.css           # QR স্ক্যান/ল্যান্ডিং ভিউ
└── js/
    ├── utils.js            # সাধারণ হেল্পার ফাংশন
    ├── main.js             # রাউটিং (hash-based), নেভ টগল, ফুটার ইয়ার
    ├── qr-generator.js     # ফর্ম, QR জেনারেশন লজিক (qrcode.js ব্যবহার করে)
    └── scan-view.js        # ল্যান্ডিং/স্ক্যান পেজ রেন্ডারিং লজিক
```

## 🧭 কীভাবে কাজ করে (রাউটিং)

এটি একটি **সিঙ্গেল HTML ফাইল**-ভিত্তিক অ্যাপ — আলাদা পেজ নেই, `main.js` hash অনুযায়ী ভিউ টগল করে:

- `#home` — হোম
- `#generator` — QR জেনারেটর
- `#about` — সম্পর্কে
- `#privacy` — প্রাইভেসি পলিসি
- `#terms` — শর্তাবলী
- `#contact` — যোগাযোগ

QR স্ক্যান করলে `?view=scan&...` প্যারামিটার সহ ওপেন হয়, যা `scan-view.js` হ্যান্ডেল করে।
